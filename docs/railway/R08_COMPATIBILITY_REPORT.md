## Implementation and policy
Single pure RailCompatibility binds R07 immutable graph and decoded R06 train profile; no graph copy or alternate runtime engine. Schema v1 policy explicitly selects Realism/Easy, reversal permission, per-edge inference entries and authorized mode-change nodes with positive switching seconds. Each traversal explicitly selects direction/from/to, gauge and diesel/electric/steam operating mode; electric selects voltage and frequency. Dual only diesel/electric, no automatic fallback. Enforce active lifecycle, allowed access, per-edge range, train gauge/traction and track gauge. Electric only with affirmative electrification and matching voltage/frequency, 0 Hz is known DC, null is unknown. Non-electric mode does not need electrical information. Track speed known or explicitly inferred; effective speed min(train,track). Numeric limits from R06. Malformed requests return INVALID_INPUT; known incompatibility INCOMPATIBLE_PROFILE; missing critical information DATA_MISSING. All results and accepted inference notices immutable.
Easy may fill ONLY null/unknown gauge, electrification, voltage, frequency and speed with explicit per-edge value and reason; no default assumptions, no override of known data, no restricted/inactive/unknown access bypass, no forbidden/unspecified turns bypass. Realism rejects any inference configuration. Contradictory inferred electrification rejected. Every used inference returned as field/value/reason for UI/quote labeling in R09/R10/R43; UI not implemented here.
Turn checks revalidate both edges, continuity, explicit permitted turn; unspecified denies both modes. Return to origin node requires reversal flag; reversal flag requires explicit policy permission. Gauge fixed across turn. Dual mode changes require explicit permitted node and positive switch time; add turn and switch penalties with checked overflow. Same-mode electrical pair changes denied pending validated system-change sites. No unsupported mode or silent fallback.
Conservative schema decisions (not source-derived physical facts): if both independent voltage and frequency lists have multiple values, reject ambiguous pair correlation; one dimension singleton interpreted as compatible listed alternatives. R12/R15 must supply verified pairs or versioned correlated model; no Cartesian inference. R06 does not encode contact system/structure gauge/length clearance or original OSM lifecycle distinctions beyond active/access, so these cannot be independently certified here. R15 must normalize/omit unsafe or unknown source restrictions and generate explicit permitted through-turns from reviewed topology; no synthetic junctions.
